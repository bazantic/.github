# Bazantic

**Proven work tools, instantly made yours with AI.**

Use the tools your peers rely on to get work done. AI makes them yours instantly. Apps, workflows, tasks and websites. No AI expertise required.

## One platform, three ways in

**Bazantic for Professionals**
Start from what a peer in your industry built and make it yours, or create your own.
→ [bazantic.com](https://bazantic.com)

**Bazantic for API Providers**
Get your API into the hands of AI users. Bring your API docs or MCP server. We build the agent interface and put it in front of AI users.
→ [bazantic.com/become-a-provider](https://bazantic.com/become-a-provider)

**Bazantic for Developers**
Give your AI the capabilities to navigate real APIs. Access APIs, orchestrate how agents use them, and cap the spend, all from your LLM client.
→ [bazantic.com/developers](https://bazantic.com/developers)

## Get the CLI

```
npm i -g @bazantic/cli
```

The `baz` command calls paid APIs, settles the payment for you, and caps what your agent can spend. [See it on npm](https://www.npmjs.com/package/@bazantic/cli).
